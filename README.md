# Blackjack Advisor v1

Enter the dealer's up card and your cards, and get a hit / stand / split / double recommendation based on a simple rule set. Tracks your results and how often you follow the advice.

## Features
- Advice for hard totals, soft totals and pairs (always split A and 8, never split 5s or 10s)
- Split hands, double down, undo
- Stats: win rate, net units, blackjacks, busts, followed-advice win rate, weak vs strong dealer
- Stats saved in the browser (localStorage)

## Run
Open `index.html` in a browser. No build step.

## Deploy
Import the repo in Vercel with the "Other" framework preset.
